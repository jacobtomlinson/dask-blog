We need to update the design of this Sphinx blog to match the design on the public Dask website.

This CSS file is a good foundation for the styles needed in this redesign. It was created as part of another site's redesign with the same goals. https://raw.githubusercontent.com/dask/dask.github.io/a1f5acf5ef038ed1f1208d36fd0641eb8557d2d9/_static/css/dask.css. Download the file locally and read it to view the changes.

The https://www.dask.org/blog page shows a design preview of what we want this new site to look like. The Index page of the blog in this repo should be made to roughly mirror https://www.dask.org/blog. Also take a local copy of these pages to make it easier to work with them.

Use the playwright-cli skill to view the site we are mirroring along with the build preview of this site. Use the local build instructions from @README.md to make a local build.
